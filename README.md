# Evolução em três dimensões

Apresentação web para a palestra **Evolução em três dimensões**, realizada para o Instituto Espírita Maria de Nazaré em 2 de novembro de 2026.

A experiência explora a relação entre amor, sabedoria, caridade e humildade ao longo do tempo, por meio de um mapa tridimensional com uma espiral evolutiva.

## Acessar a apresentação

Abra [index.html](index.html) no navegador. A página é estática e não exige instalação de dependências nem etapa de compilação.

A jornada é percorrida verticalmente com a rolagem. Conforme cada etapa entra em foco, o mapa destaca os eixos correspondentes. A apresentação adapta-se a telas de computador e dispositivos móveis.

## Publicar com GitHub Pages

1. Envie o conteúdo deste repositório para o GitHub.
2. No repositório, acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch publicada (por exemplo, `main`) e a pasta `/(root)`; salve.
5. Após a publicação, o site estará disponível na raiz do endereço do projeto.

Para este repositório, o endereço esperado é [https://deusanyjunior.github.io/evo3d/](https://deusanyjunior.github.io/evo3d/).

## Estrutura

- [index.html](index.html) — conteúdo e estrutura da apresentação.
- [styles.css](styles.css) — estilos, layout responsivo e apresentação visual.
- [script.js](script.js) — desenho dos gráficos e acompanhamento da etapa ativa durante a rolagem.
- [instruções.md](instruções.md) — texto de referência e conteúdo-base da palestra.

## Tecnologias
